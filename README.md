# Замер скорости скачивания

Скрипт выполняет 10 последовательных HTTP GET к одному URL и дочитывает тело каждого ответа перед следующим запросом. Нужен Python 3.10 или новее. Сторонние зависимости не нужны.

Передайте прямую ссылку на достаточно большой файл. Например, замените адрес в этой команде на свой:

```sh
python3 speed_test.py 'https://example.org/path/to/large-file.jpg'
```

Чтобы проверить запуск без внешнего сайта, выполните в первом терминале из папки проекта:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Во втором терминале из той же папки:

```sh
python3 speed_test.py http://127.0.0.1:8000/README.md
```

Локальный пример проверяет работу скрипта. Для замера интернет-соединения используйте удалённый URL.

## Как считается результат

- **Среднее время, мс** — от начала запроса до чтения всего тела ответа, в среднем по 10 запросам. В это время входит ожидание ответа сервера.
- **Общий объём, Б** — сумма прочитанных байтов тел ответов. Заголовки и сетевые накладные расходы не учитываются.
- **Скорость, Мбит/с** — общий объём в байтах × 8 ÷ суммарное время в секундах ÷ 1 000 000.

Скорость относится к конкретному URL и зависит от сервера, маршрута и размера файла. Скрипт запрашивает ответ без сжатия и просит промежуточные кэши перепроверять свежесть файла. При редиректе, HTTP-ошибке, неполном ответе с указанным размером или сетевом сбое выводится ошибка с номером запроса. Тайм-аут отдельной сетевой операции — 15 секунд. Для URL с редиректом используйте конечный адрес.

## Проверки

```sh
python3 -B -m unittest -v
```

Тесты запускают локальный HTTP-сервер. Они проверяют число и порядок запросов, объём, расчёт скорости, отказ при обрыве и отсутствие перехода по редиректу.
